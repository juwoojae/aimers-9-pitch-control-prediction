# 결정 및 이슈 기록

## 상태 표기

- `확정`: 공식 규정 또는 데이터로 검증됨
- `결정`: 팀이 근거를 갖고 선택함
- `가설`: 실험 전 아이디어
- `미확정`: 추가 확인 필요

## 기록

### 2026-08-08 — 프로젝트 문서 초기화

- `확정` 예측 단위는 개별 투구이며 Target은 `control_success`이다.
- `확정` 출력은 제구 성공 가능성을 나타내는 확률이다.
- `확정` 현재 투구 직전까지 알 수 있는 정보만 사용할 수 있다.
- `확정` 평가 지표는 Brier Skill Score이다.
- `확정` 실제 평가 샘플은 245,789개이고 전체 추론 제한은 10분이다.
- `확정` 제출은 `model/`, `script.py`, `requirements.txt`를 포함한 ZIP 형식이다.
- `확정` Public Score는 테스트 데이터 100%로 계산되고, Private Score는 대회 종료 시점의 Public Score이다.
- `확정` Phase2 수료 기준 Public Score는 `549.51`이다.
- `확정` 평가 서버는 Ubuntu 22.04.5 LTS, Python 3.11.15, CUDA 12.8 환경이다.
- `확정` 평가 서버 기본 Python·시스템 패키지 목록을 `docs/02_competition_and_submission.md`에 기록했다.
- `확정` 설치 오류는 일일 제출 횟수에 반영되지 않지만, `script.py` 실행 이후의 제출 오류는 반영된다.
- `확정` 공식 배포 데이터와 베이스라인 제출 예시를 프로젝트에 추가했다.
- `확정` train은 1,475,092행×49컬럼, Trackman은 1,793,078행×30컬럼이다.
- `확정` 로컬 test와 sample submission은 형식 확인용 5행이며 실제 평가 시 245,789행으로 교체된다.
- `확정` 배포 구조와 베이스라인 코드 모두 평가 입력 경로로 `data/`를 사용한다.
- `결정` 데이터 스키마 확인 전에는 구체적인 피처나 split을 확정하지 않는다.
- `결정` 모든 과거 이력 피처는 현재 행을 제외하고 계산한다.
