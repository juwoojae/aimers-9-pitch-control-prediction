# 문제 정의

## 한 문장 정의

투구 직전까지 관측 가능한 정보만으로 해당 투구가 원하는 제구 범위에 성공할 조건부 확률

\[
P(\texttt{control\_success}=1 \mid \text{현재 투구 직전까지의 정보})
\]

을 예측한다.

## 배경

평균자책점, 볼넷 수, 스트라이크 비율 같은 경기 후 집계 지표만으로는 실제 투구 당시의 의사결정 맥락을 충분히 설명하기 어렵습니다. 제구는 볼카운트, 주자 상황, 타자와 투수의 특성, 과거 투구 흐름 등이 함께 작용하는 사건입니다.

따라서 이 프로젝트는 경기 종료 후 선수를 평가하는 문제가 아니라, **매 투구 직전 시점의 정보를 사용해 다음 결과의 확률을 추정하는 문제**로 다룹니다.

## 예측 대상

- 관측 단위: 개별 투구
- Target: `control_success`
- 학습 레이블: 성공 `1`, 실패 `0`
- 모델 출력: `[0, 1]` 범위의 성공 확률

확률 `0.8`은 같은 조건의 투구가 충분히 반복될 때 약 80%가 성공한다는 의미에 가깝도록 보정되어야 합니다. 임계값으로 0/1을 잘 맞히는 것만으로는 충분하지 않습니다.

## 제구 성공과 실패의 정의

제공된 설명에 따르면 유효한 투구 중 다음 세 경우가 제구 실패이며, 나머지는 성공입니다.

1. 스트라이크존 가운데 부근으로 들어간 공
2. 스트라이크존에서 크게 벗어난 공
3. 포수의 요구 방향과 반대로 들어간 공

이 정의는 레이블 생성 기준입니다. 현재 투구가 끝난 뒤에만 알 수 있는 실제 공 위치나 결과 컬럼은 모델 입력으로 사용할 수 없습니다.

## 사용 가능한 정보의 경계

사용 가능 여부는 컬럼 이름이 아니라 **그 값이 언제 확정되는지**로 판정합니다.

| 정보 | 원칙적 판정 | 비고 |
|---|---|---|
| 현재 투구 전 볼카운트 | 사용 가능 | 데이터 정의 확인 필요 |
| 현재 투구 전 주자·아웃 상황 | 사용 가능 | 데이터 정의 확인 필요 |
| 타자·투수의 사전 정보 | 사용 가능 | 해당 경기 시점 이전에 알려진 값이어야 함 |
| 과거 투구 이력 | 사용 가능 | 현재 투구를 반드시 제외 |
| 2019~2024 Trackman 과거 특성 | 보조 데이터로 사용 가능 | 조인 키·기간·규정 확인 필요 |
| 현재 투구의 최종 위치·구속·회전 등 | 원칙적으로 사용 불가 | 투구 직전에 알 수 없는 실측 결과인 경우 |
| 현재 투구 판정·타격 결과 | 사용 불가 | 명백한 사후 정보 |
| 이후 투구 또는 경기 종료 집계 | 사용 불가 | 미래 정보 |

최종 판정은 실제 `data_description.md`와 데이터 생성 시점을 확인한 뒤 [데이터 사전](04_data_dictionary.md)에 기록합니다.

## 성공 기준

프로젝트의 성공은 다음 네 조건을 함께 만족하는 것입니다.

- 검증 Brier Skill Score가 단순 기준 확률보다 안정적으로 높다.
- 선수·경기·시간 경계를 넘는 데이터 누수가 없다.
- 예측 확률이 잘 보정되어 있다.
- 전체 제출 파이프라인이 공식 서버 제약 안에서 재현된다.
